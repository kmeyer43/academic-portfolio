# Academic Portfolio — Week 2 Starter

This is a **simple framework**, not a finished portfolio. It's intended for the Week 2 CVTC portfolio-platform discussion and can grow throughout the remaining weeks.

## What's included

- `index.html` — the whole website (HTML and a small amount of CSS)
- `README.md` — these instructions

Current sections: About, Academic Projects, Skills & Tools, Education, Contact. Projects and contact details intentionally contain placeholders.

## Preview on your computer

Double-click `index.html` to open it in a browser. No software installation or build process is required.

## Publish for free with GitHub Pages

1. Create a **public** GitHub repository, e.g. `cvtc-academic-portfolio`.
2. Upload `index.html` and `README.md` to the **top level** of the repository (not inside a folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** and choose **main** and **/(root)**, then save.
5. GitHub will provide the website address. For this repo name, it will generally be:
   `https://YOUR-USERNAME.github.io/cvtc-academic-portfolio/`

The website is not published until you complete these steps.

## Update it each week

Edit `index.html` in a text editor, save, and upload/commit the new version to GitHub. Replace placeholder project cards with details from your actual assignments. Suggested details:

- Project title and objective
- Tools or software used
- Data source and analysis steps
- Main findings or lessons learned
- Screenshot or link to the project files

Keep the site simple for now. You can adjust colors, layout, and features near the end of the program if you want.

## Privacy check

Before making the repository public, only add email, resume, or project data that you are comfortable publishing. Do not upload private employer data, passwords, or sensitive student information.
