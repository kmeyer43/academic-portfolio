## Publish in your existing GitHub repository

Repository: `https://github.com/kmeyer43/academic-portfolio`
Website: `https://kmeyer43.github.io/academic-portfolio/`

1. Extract this ZIP.
2. Open your GitHub repository in a browser.
3. Choose **Add file → Upload files**.
4. Drag the **three files** (`index.html`, `block1.html`, `README.md`) into the upload area, not the folder or ZIP.
5. If asked, let `index.html` and `README.md` replace the existing versions, and commit the changes to `main`.
6. After GitHub Pages deploys, visit `https://kmeyer43.github.io/academic-portfolio/block1.html` and test the new navigation link from the homepage.

Or, if you use GitHub Desktop, copy the three files into the local repository, review the changes, commit, and push.

**Don't create a new repository** — these files are designed to update the existing one.

## Before you submit the lab

The directions ask you to demonstrate competency, not just summarize classes. To make this more convincing, replace at least one placeholder for each course with a real artifact, such as:

- Intro: flowchart, pseudocode, CLI, or early programming screenshot
- Database 1: a SQL query or entity relationship diagram
- Systems Analysis: requirements document, system design diagram, or project plan
- Excel: a sheet showing formulas, conditional formatting, or a chart

Do not upload sensitive information or assignments that cannot be made public. You may use sanitized screenshots instead.

**Important:** The website layout and course summaries are ready, but actual course artifacts were not provided and are intentionally not fabricated.
